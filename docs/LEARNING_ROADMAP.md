# ZOPAIR ARMY Academy Roadmap

## Phase 1 — Foundation
- curriculum and prerequisites
- independent evaluation
- learning memory
- bounded retries

## Phase 2 — Mastery
- promotion gates based on repeated evidence
- spaced repetition and review scheduling
- performance-aware routing

## Phase 3 — Adversarial training
- prompt-injection resistance
- least-privilege exercises
- false-success detection
- runaway-cost controls

## Phase 4 — Controlled evolution
- generate candidate lessons from sanitized failures
- version skills and lesson definitions
- regression-test every promoted skill
- rollback on degraded benchmark performance

## Phase 5 — Swarm knowledge
- share only approved, sanitized lessons
- distinguish agent-specific experience from global knowledge
- prevent one bad experience from becoming global truth
- use confidence and provenance for every learned artifact

## Non-negotiable rules

1. Learning cannot silently grant permissions.
2. Production credentials and secrets are never training material.
3. Agents cannot approve their own promotion.
4. A single successful run is insufficient for mastery.
5. Security and policy changes require human approval.
6. Every promoted skill remains versioned and rollbackable.
7. Benchmark regressions block promotion.

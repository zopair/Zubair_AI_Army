# Zopair Agent Lab — Controlled Live Experiment Protocol

## Purpose
Run the first real-world micro experiment without committing Zopair funds, exchange keys, wallet keys, or cloud credentials to the repository.

## Phase A — qualification
- Select one lawful digital-service task with an observable deliverable.
- Use a test/sandbox account or a task that requires no privileged credentials.
- Record baseline human effort and expected market price before execution.

## Phase B — candidate execution
Run the same task with OpenHands, Agent Zero, and CrewAI where technically applicable. Keep prompts, input data, time limit, and task specification constant.

## Phase C — accounting
Record:
- gross customer payment (if any)
- compute cost
- API cost
- platform fees
- human review time
- refunds/rework
- net contribution

Revenue must be verified from the actual payment/marketplace record. Synthetic estimates are never recorded as revenue.

## Phase D — promotion
A candidate can be promoted only when it has:
1. verified positive net contribution;
2. repeatability on at least 3 comparable tasks;
3. no unresolved critical safety/security issue;
4. documented stop conditions;
5. no credentials committed to Git;
6. a bounded budget and rollback path.

## Phase E — scale
Scale only the winner. Increase one variable at a time: task volume, concurrency, or compute budget. Keep a control sample to detect regression.

## Hard prohibitions
No market manipulation, wash trading, fake volume, deceptive promotion, unauthorized access, credential harvesting, or automated financial transactions are part of this experiment.

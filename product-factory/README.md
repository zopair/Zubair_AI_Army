# ZOPAIR Product Factory

A reusable product-launch template for turning a validated ZOPAIR capability into a discoverable, testable and sellable developer product.

## Factory stages

1. Problem brief
2. Market/keyword evidence
3. Minimal implementation
4. Contract + regression tests
5. Documentation and examples
6. Demo/landing page
7. Usage metering
8. Pricing experiment
9. Release
10. Observability and unit-economics review

## SEO principle

Optimize for useful discovery, not keyword stuffing. Every published page should answer a real developer question, contain original documentation/examples, expose canonical metadata, and link to the relevant product documentation.

## Promotion gate

A product graduates from factory prototype to catalog listing only when it passes correctness, security, reliability and unit-economics gates.
